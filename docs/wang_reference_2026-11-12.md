# Wang局部参考机制适配（2026-11-12）

从cac2de3派生，新分支research/wang-reference-2026-11-12，原工程与此前阶段保留。依据本机Wang等《Simultaneous Planning and Tracking Framework for Obstacle Avoidance of Autonomous Mobile Robots in Dynamic Scenarios》（IEEE TIE 2025，DOI 10.1109/TIE.2024.3522489）III-B与式(16)，新增仅用于单机直线的最近参考投影。使用自机位置与原观测参考的切向，不读取动态障碍真值，不改变领导者/观测器，不制造侧向路径。原TimedReference和默认行为保留。

这是论文机制适配，不是完整复现：连续直线投影代替最近离散全局点，仍使用本工程非线性联合MPC与权重、包络与CV预测，不实现论文误差线性化/IMM/事件触发。最近路径跟踪不等于按时领导者跟踪；两类误差必须分别保留。

实验前冻结计划：纯Python固定active_overtaking、40秒，legacy（原N10引导）、wang_timed（N25/椭圆/反比代价beta=.3/关闭引导）、wang_nearest（与wang_timed仅参考不同）三次。理想状态/预测、每步0.5秒离线预算，不能称实时效果。随后只做两次Gazebo接线/实际感知适配对照，种子211，实际100ms控制预算，场景和连续验收不修改；结果好坏均保存。

## 实现边界

| 项目 | 本阶段处理 |
|---|---|
| 论文最近参考点与式(16) | 投影到原观测参考的支撑直线，保留节点间隔与速度；不是离散全局路径点搜索 |
| 非直线/非均匀观测预测 | 拒绝本次投影，退回原定时参考，逐周期记录原因；不把弯曲预测偷偷改成直线 |
| 论文误差模型、控制误差代价 | 保留原非线性模型/辅助规划变量/绝对控制代价，尚未移植其完整误差状态优化问题 |
| 安全空间与软代价 | 使用已有同禁止区域椭圆条件及式(14)反比代价适配；保留原执行裕量和协方差膨胀，不假定传感器无误差 |
| 障碍预测 | 实际控制仍为本机雷达/CV；未实现原论文IMM |
| 求解 | CasADi/IPOPT与既有初值/后备保留；周期重算，未实现事件触发 |
| 输入与目标 | 原速度界、领导者与观测器更新、误差公式不变；不强加正速度下界，不关闭紧急停车 |

因此本阶段只能称“Wang最近参考机制＋既有核心适配的对照”，不能称论文方法完整复现，也不能用其结果否定原作者结论。

## 冻结计划的五次运行

所有任务均完成40s，仍采用上一阶段事前冻结的active_motion协议；没有调整障碍位置、尺寸、速度或验收门槛。理想实验无雷达/刷新误差，额外求解预算不计作实时能力。两次Gazebo使用同一来源代码、CV、本机雷达、种子211、H25与100ms预算，只有local_reference_mode不同；闭环轨迹不同，传感器测量也会不同，不能称逐帧相同输入。

Gazebo最近参考在400个有输入快照的周期中应用318次，82次因观测预测不满足均匀直线前提而撤销，另1周期为stale_data且无求解输入。因此它是有明确撤销规则的混合适配，不冒称401周期均为纯最近参考。理想最近参考没有该问题，仍跟在慢障碍后面，说明仅修复这82次撤销不足以推断效果就会改善。最近参考消除了沿路径的时间追赶压力，局部跟踪目标好看不代表原领导者编队误差变小。

定时/最近Gazebo分别45/16次solver_failed_stop，逐帧重放全部确认当时模型h0低于既有-2e-6前提容差；不是45/16次IPOPT迭代超时。这时更新后的膨胀椭圆已不满足当前安全域前提，比较模式按原规则拒绝求解/后备。模型h0负不等于物理碰撞，两次实际圆形代理净距均为正。另有预算退出User_Requested_Stop，可行迭代/后备与失败分别记录，没有将全部退出归为不可行。

356+384=740条已采用的验证指令，通过精确输入下的首步输入界/所选椭圆模型重放；45+16次故障停车另计，最近组1次无快照stale_data另计。这只检查离散首步模型，不能证明全窗口/连续物理安全。两次指令耗时P95约83.54/84.89ms，不据此声称比原控制器更快。

## 对称性与初值的事后诊断

固定理想定时组在4s和20s的状态/目标/模型，每帧试直行、左弯、右弯三个初值；这是看到闭环结果后的解释性分析，不计作额外闭环成功或事前验证。

- 4s三种初值均收敛到直行，目标值约5.7082。该短窗口/权重下，换左右初值并未推动提前绕行。
- 20s直行初值仍跟车，目标值3143.066；左右初值可找到经原模型验证的对称绕行解，目标值2921.949。但首控制约v=-0.204m/s、omega=±2.84rad/s，是倒车急转，不能作为流畅向前绕行的证据。

这提供了局部解依赖初值的具体证据，同时说明“多加几个初值”不足以解决提前、持续、平滑三个要求。对称同车道时，仅有距离代价不会自动指定左右；跟车状态仍有位移，现有停滞触发也不必然启动选侧。最近参考本身不是绕行路径生成器。

## 结论与下一步

179项检查、构建、参数展开及实际接线验证通过；算法效果验收0/5，完整保留失败。未接受为默认效果改进，不进入五机或实物。原MPC核心、旧场景和验收协议相对cac2de3未改；默认仍timed，原工程不写回。

下一阶段应围绕“有限速度下提前选择可达侧向绕行，并保留定时追赶能力”设计参考/初值协调，而不是继续单独叠加反比代价或把最近参考当作解决方案。先在固定追越场景检验完整侧移、通过及回归，保留原DCBF和应急停车；不能用延长任务、提高速度或放松验收取得通过。论文完整复现仍有上述模型/代价/预测/触发缺项。
