# 阶段来源与保留范围

本仓库保留当前 CV 源码以及两个静态阶段标签，原始大型实验数据和完整工程归档位于本地独立保留目录。

- `teacher/static-2026-10-20-r04`：8 项核心执行源码与当时静态 180 秒快照逐项 SHA 一致；其余通用源码／资产由保留工程补齐。
- `teacher/static-2026-10-21-r05`：控制器、leader、结果脚本、launch 等与动态改造前原始静态备份一致；共享优化器与 20 日已验证原件一致。`cbf_mpc_core.py` 的默认半径依据当时记录的单行 `.4 -> .5` 差异恢复。不是整个工作站的逐字原始镜像。
- `baseline/cv-dynamic-2026-10-24`：已验证动态算法的初始本地源码提交；标签于 10 月 26 日归档时创建，日期表示算法阶段。

静态恢复工作空间已独立构建，并通过 14 项适用数值检查；未在恢复时重跑完整 180 秒。CV 副本独立构建和 37 项检查通过，ROS 包定位核验正确。

两个 `static*_provenance.json` 保留关键文件来源和 SHA；`cv_dynamic_validation.json` 保留单次验证摘要。SHA 清单只能关联对应版本，不能把不同参数、不同半径的结果混为同一实验。

不发布内部恢复复制态标签。默认忽略实验输出；本地保留的失败记录没有删除。正式论文性能比较仍需统一评价口径并增加重复试验。
