# 名义主线与可选整帧置信对照

按用户要求，把新增360束联合99%保护降为可选研究对照，主线先集中联合规划跟踪、动态预测和五机协调。不关闭Gazebo原有Gaussian雷达噪声σ=.01，不删除旧算法、数据或已发现漏包。

新入口`five_turtlebot3_cbf_nominal_mainline.launch`，默认`protection_mode=nominal`。保留原圆弧观测/可信圆保持、CV跟踪、参考项目原协方差膨胀及原车体/执行裕量。关闭整帧置信、圆盘交集、新代价准入和预算/调度试验；仅保留纯日志内存压缩，完整已记录输入仍落盘。实际噪声、桶R.12、编队R.4、速度/硬DCBF/100ms截止/原小桶协议不变。

没有可信圆、仍为可见面MVEE时，用已知桶R和现有拟合padding=.03作名义轮廓补全：回波质心作外包圆中心，半径至少2R+padding，并保持完整测量椭圆包含。不把该质心作为新的物体位置测量，KF位置/速度/P更新不变。无噪声纯单体回波质心在物体包围圆内，2R可补全实体；padding为原几何工程项，Gaussian误差无有限硬界，**不声称99%或真实世界绝对安全**。未知物体、混簇、半径错误和真实定位漂移仍需验证，不能直接把小桶假设套给小车。

`protection_mode=scan_confidence`保留已提交的联合置信集合算法，其他控制/噪声/日志设置与名义方案一致。对比是两套初始化保护策略的整体比较，不把所有差异仅归因99这个数字。旧联合置信代码及其局限不改，原main/root src不变。

265项检查通过：稀疏弧实体补全/原测量包含、只改几何而不改运动、两套保护互斥。旧R.12无保护三场景15份同输入反事实，原记录验证器独立，运动误差数值完全一致，原18帧反例仍被名义保护覆盖，有限窗口圆轮廓检查通过，不推广为全局概率保证。

先冻结，再顺序运行名义三类＋置信对照三类，seed211各40s。各自完整保存结果，不删掉原严格判据或将未过改成通过；同时分别报告净距、恢复、停滞/速度和耗时，0/3工作验收不等同论文是否成立。主线的最终选择仍由数据决定，不预称稳定。

## V1开发结果与V2修正

V1名义三场景均完成，但迎面明显停滞；固定2R外包圆尽管简单，会把部分可估计的圆心不确定性保留得过大，不直接提升该版。V1及置信对照首次控制前Gazebo原生段错误全部保留。

V2仅在原自由圆拟合失败时，用已知R=.12作两参数圆心最小二乘估计：使用至少3个点、鲁棒迭代与条件数/残差/近似精度/传感器朝向门槛，原三参数自由圆的6点/弧长质量门槛不改。估计通过则以R＋原padding及完整测量包含形成圆观测，沿用原KF/CV/协方差膨胀；不通过才使用V1名义补全。无整帧99%、无1cm硬界主张。已知桶尺寸是额外先验，此模式不覆盖未知形状或未经标定的小车。

V2会改变低质量弧阶段的位置/运动估计（原跟踪目标和观测公式不改），不能再称所有运动估计值与V1相同。267项检查通过，旧15份原记录独立校验及同输入反事实的有限完整圆覆盖通过，原18帧缺口保留验证。对照仍只改变保护方案整体，不能仅以99%数字解释差异。

## 验证与保留

本轮共11次尝试：V1名义3次完成＋置信启动原生崩溃1次；V2名义追越完成、迎面启动崩溃后保留并新目录完成其余5次。合计9次完整闭环，原严格0/9；不把两次控制前段错误当算法轨迹，也不隐藏失败。各源码清单匹配24811c9/0e23468对应版本。首次分支压缩V1等既有实验没有覆盖。

267项单元检查通过，旧15份同输入反事实保留独立原验证器；V2稀疏弧圆心估计会改变运动数据，不能继续套用V1的“运动估计数值完全相同”结论。原领导者观测/编队目标/误差公式、原KF更新形式和原协方差膨胀、原MPC内核/硬约束字节保持。只有保护和观测预处理改变，σ的物理配置没有清零。

9次完整实测的17909条已采用命令首步、指标/测量包含/对应保护审计与75805项显示几何检查通过；已保存行输入快照没有缺失。45份观测重放15040次扫描/14315次控制预测差0。V2标记窗口的30份观察者、4583个唯一目标帧中，当前/1s/2s软延拓完整评估圆与膨胀代理检查未见原类覆盖缺口；未匹配帧不填零。以上不是连续物理安全证明，故障零命令不自动认证。

## 后续主线选择

按用户意见，将V2名义方案作为更简洁的后续研究候选，整帧置信仅作可选鲁棒性对照，不作为论文硬标准或独立创新点。候选不等于稳定版，当前仍有耗时和斜向低速/协调不足。后续集中重计算与发布路径隔离，以及多机侧别/通道/回归协调；不再为了99%射线事件扩展主线。若做概率安全贡献，需另行明确标定与理论范围，而非把名义padding当噪声硬界。

## 启动

在活动研究副本根目录：

```bash
source /opt/ros/noetic/setup.bash
source devel/setup.bash
TURTLEBOT3_MODEL=burger roslaunch tb3_distributed_control five_turtlebot3_cbf_nominal_mainline.launch
```

默认名义方案，可选`scenario:=active_head_on`/`active_oblique_crossing`。需要完整可选置信对照时加`protection_mode:=scan_confidence`。默认参数不关闭雷达噪声；只关闭新增置信集合、代价准入和预算/调度试验。原参考不确定性、车体/执行裕量和纯日志压缩保留。该入口仍是待改进研究版本，不保证任意实物/未知形状。

数据在根目录`四脚本对比证据/名义主线与置信对照_2026-11-23`，V1/V2所有失败、startup退出139及stdout均保留；`figures/nominal`和`figures/scan_confidence`为同风格总览，图目录软链接指向原始案例，不复制篡改数据。汇总`all_validation.json`；独立归档`阶段成果归档/2026-11-23_名义主线与置信对照`。日期为开始阶段标识，运行时间见各数据metadata。Git只上传源码/配置与聚合报告，原始数据和图像留本地。
