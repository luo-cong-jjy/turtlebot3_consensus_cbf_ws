# 五机动态避障：独立验证阶段

用户要求跳过0.8m双机，直接测试半径0.4m的正五边形。继承d227d80完整组合，原工程src及旧单/双机入口保留。

新增入口`five_turtlebot3_cbf_motion_geometry.launch`：五台初始已成队，领导者(0,0)、直线0.15m/s、40s；CV/circle及先验保持、0.22m预测触发、原生预览、预算保护与提前回归。沿用双机后方偏好，独立五机开关限定作用域。原N10、dt=.1、限速、硬DCBF、膨胀/裕量及各自本机scan不改。只允许显式五机研究入口，不自动开放其他五机组合。

初始邻距0.470228m，基础peer边界0.32m，名义h=.150228m。此计算不是实测或动态安全证明。

实验前固定`config/cbf_five_robot_protocol.yaml`，不改旧双机协议。所有5台使用原[4,39]连续运动/不爬行/无故障停车及终点恢复标准，增加全部10对采样及线性扫掠净距、末相对误差≤.10m。按名义CPA与.31m物理代理组合半径，迎面/追越要求0、2、3号空间绕行，斜向要求0、3、4号；其余仍须安全、连续前进和恢复。临时队形形变允许，不称刚性保持。此阶段没有独立五机全程可行性见证，失败不等于场景在任意策略下不可行。

计划在同一V1源码下顺序运行追越、迎面、斜向(211)，保留全部失败；不减小安全半径、延长100ms控制截止或删除故障记录。独立真值只评估，各机点簇仅本地落盘。根据真实结果判断能否给出推荐入口，未测试前不宣称通过。

## 实测结果：4次完成，严格验收1次通过

V1集成冻结为`3af2d2b`，四次试验逐文件源码清单均匹配该提交。所有试验40s结束并正常保存结果，全部五台只订阅各自scan，没有真值控制输入；本地处理点簇没有进入公开预测消息。未修改求解器、核心MPC数学、领导者观测、误差公式或安全半径。

| 场景（seed=211） | 严格验收 | 全队最低1s速度m/s | 邻机最小线性扫掠代理净距m | 末最大pair误差m | 最大记录耗时ms |

四次所有机器人对动态圆柱和全部10对邻机的采样/线性扫掠代理净距均正，动态最小代理净距约.18121m；末队形均恢复。但中间有明显形变，最大pair误差可超过1m。不能仅凭末误差小或零代理碰撞称整体效果稳定，1/4只是本批有限验收计数，不是统计成功率。GUI复测不同，不能只把变化归因于GUI；ROS/Gazebo调度非位级确定。

追越[4,39]窗口：2/3/4号分别3/2/4次故障指令，其最低1s速度仍较高，严格无故障条件未满足；全程还存在窗口外截止记录。例：2号5.862s，命令墙钟101.91ms、最终记账102.42ms，IPOPT38.27ms、校验40.04ms，周期CPU57.68ms；可行候选被截止规则拒绝，不能等同数学无解。28.362s输入准备17.76ms、manager98.93ms，总命令116.78ms。日志证明NLP以外开销和调度等待都值得检查，单纯把Python换C++或换IPOPT未必覆盖这些开销。

斜向不同：最大记录耗时92.69ms，0号4次是求解失败而非超100ms。0号约7–16s的90个参考决策中，89次`no_valid_spatial_reference`；8.553s候选原N10最差约束为peer_2、松弛−.001739，随后peer_3；3号约8.908s受peer_0约束。原硬约束筛掉参考后使用短步后备，虽避免本批代理碰撞，仍发生绕行不足、低速和倒车。3号最长停住.341s、0号.282s，原标准.25s。说明原单机侧移族在紧邻五机下可能相互阻挡，不能通过放宽停车验收或缩小包络掩盖。

8013条**已采用**控制首步模型重验、4份误差口径及几何包含审计、34655项预测显示检查通过；故障停车单列，未将零命令自动认证安全。几何包含只验证原测量椭圆/点及保持先验，未证明真实物体始终在估计内，也未新验证五机估计速度精度。旧单/双机试验仍独立保留。

## 下一步与启动

优先沿这份失败记录做分布式邻机绕行协调：在原候选筛查中同时考虑邻机预测与可达侧别，检查是否需要小状态的固定优先关系/侧别滞回，避免各自侧移和回归互相封路；不共享点云，不先改.4半径或硬安全边界。并行研究控制周期的输入、求解后校验及预算预留，目标是原100ms内完成，而非调大截止。先重跑同三场景及重复，再考虑新种子和实物。此处是下一阶段方案，尚未实现或宣称创新。

当前五机入口仅供复现候选版本，**不推荐作为已稳定演示版**。在研究副本执行：

```bash
source /opt/ros/noetic/setup.bash
source devel/setup.bash
TURTLEBOT3_MODEL=burger roslaunch tb3_distributed_control five_turtlebot3_cbf_motion_geometry.launch scenario:=active_head_on
```

默认同时打开Gazebo和RViz，选中0号本地预测显示；其余四台预测可以分别选择各自topic。实际RViz截图中五台、队形连线、邻机和动态预测显示存在，但界面继承基线布局、截图窗口较大，尚未做五机视角排版优化。
